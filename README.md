# RNA-seq Bioinformatics Pipeline

This GitHub page is a collection of scripts and general code used for the analysis of RNA-seq datasets

Make sure these dependencies are installed in your system:

- anaconda3
- python (version 3.9)
- fastp v0.23.4
- FastQC v0.11.9
- STAR v2.7.10b
- Subread v2.1.1

For other analyses, install or clone Github repositories:

- R
